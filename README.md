# GreenLeaf — мир комнатных растений

[![Deploy static site](https://github.com/hudenkodi-collab/greenleaf-site/actions/workflows/deploy.yml/badge.svg)](https://github.com/hudenkodi-collab/greenleaf-site/actions/workflows/deploy.yml)

Учебный проект по дисциплине «Информатика». Сайт создан в лабораторной работе №4
и доработан в лабораторной работе №5: добавлена фотогалерея из трёх изображений,
фотографии перенесены в локальную папку `images`, исправлена подпись кнопки формы
обратной связи. В лабораторной работе №6 настроен автоматический деплой через
GitHub Actions.

## Публикация

Сайт опубликован с помощью GitHub Pages:
https://hudenkodi-collab.github.io/greenleaf-site/

## CI/CD-пайплайн

Workflow `.github/workflows/deploy.yml` запускается при каждом push в ветку `main`
и при ручном запуске. Он состоит из двух заданий:

1. **Validate HTML and CSS** — устанавливает Python и запускает
   `scripts/check_site.py`. Скрипт проверяет структуру HTML, подключение внешней
   таблицы стилей, баланс скобок в CSS, наличие локальных файлов и внутренних
   якорей. Если проверка не пройдена, деплой не выполняется.
2. **Deploy to GitHub Pages** — копирует репозиторий на runner, готовит окружение
   Pages, упаковывает сайт в артефакт и публикует его действием
   `actions/deploy-pages`.

Статус последней сборки отображается бейджем в начале этого файла.

## Структура проекта

- `index.html` — главная страница сайта;
- `style.css` — стили сайта;
- `scripts/check_site.py` — автопроверка качества перед деплоем;
- `images/` — изображения, используемые на странице;
- `docs/` — материалы отчёта;
- `materials/` — дополнительные графические и текстовые материалы;
- `.github/workflows/deploy.yml` — CI/CD-пайплайн GitHub Actions.

## Локальная проверка

```bash
python scripts/check_site.py
```

## Ветви проекта

- `main` — основная ветвь с опубликованной версией сайта;
- `feature-gallery` — добавление локальных фотографий и новой галереи;
- `docs` — текстовые материалы и отчёт;
- `media` — графические материалы для отчёта.
