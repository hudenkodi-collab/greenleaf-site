# GreenLeaf — мир комнатных растений

Учебный проект по дисциплине «Информатика» (лабораторная работа №5).
Сайт создан в лабораторной работе №4 и доработан в лабораторной работе №5:
добавлена фотогалерея из трёх изображений, фотографии перенесены в локальную
папку `images`, исправлена подпись кнопки формы обратной связи.

## Структура проекта

- `index.html` — главная страница сайта;
- `images/` — изображения, используемые на странице;
- `docs/` — материалы отчёта;
- `materials/` — дополнительные графические и текстовые материалы.

## Публикация

Сайт опубликован с помощью GitHub Pages:
https://hudenkodi-collab.github.io/greenleaf-site/

## Ветви проекта

- `main` — основная ветвь с опубликованной версией сайта;
- `feature-gallery` — добавление локальных фотографий и новой галереи;
- `docs` — текстовые материалы и отчёт;
- `media` — графические материалы для отчёта.
